# S04 - Semana de Trofeo Mayor y Actualización de Bitácora

**Fecha:** 3 de Septiembre 

**Participantes:** Marcos, Thiare, Byron, Catalina

## Objetivo de la semana
Justificar la pausa de actividades de campo e investigación del proyecto Capstone y utilizar el periodo para la actualización administrativa del repositorio del equipo Capstonersitos.

---

## 1. Suspensión de Actividades (Trofeo Mayor)

Durante la presente semana no se llevaron a cabo sesiones regulares de avance técnico, reuniones con el cliente ni validaciones en terreno. Esto se debe a la suspensión oficial de actividades académicas en la universidad por la realización del **Trofeo Mayor**. 

Por este motivo, el desarrollo del prototipo y el trabajo de investigación para el desafío del Hub Providencia se mantuvieron pausados, retomando la planificación normal a partir de la semana siguiente.

## 2. Trabajo Administrativo y Repositorio

A pesar de la pausa de clases, el equipo aprovechó esta ventana de tiempo para realizar labores de control de gestión interno:
*   **Actualización de Bitácora:** Se revisaron y editaron las entradas anteriores en GitHub (S01, S02, S03) para asegurar que la documentación en formato Markdown estuviera correcta.
*   **Gestión de Archivos:** Se estructuraron las carpetas de imágenes y se verificaron los enlaces del portafolio para garantizar que toda la evidencia visual de los mapas y análisis previos se visualice correctamente de cara a las próximas evaluaciones.
